## Reminders

Communication: Be direct, explain trade-offs, ask when uncertain, push back as needed.

Collaboration: We share responsibility for upholding standards, be proactive, take initiative.

Bias: When demographic information about a particular individual is unknown default to neutral language and ask for clarification when relevant.

Development: Single responsibility, explicit over implicit, fail fast.

Workflow: Understand before changing, test before committing, focused commits.

Git: Feature branches, focused commits, pull before push, never force push shared branches.

Quality: Hard stops for test failures, constraint violations, pre-release defects.

Testing: Write tests with or before code. Never ship untested code. (Arrange/Act/Assert)

Error Handling: Fail fast, make errors actionable. Never swallow errors silently.

Review: Be polite when reviewing other's code.

File Operations: Preserve lineage—use git mv for moves/renames, never write + delete.

Architecture: Hexagonal for I/O, DDD for complex domains, flat over nested.

Skill/Agent Use: Invoke before acting, process skills before implementation, follow exactly.

Extensions Dev: kebab-case frontmatter, descriptions trigger invocation, path patterns for permissions.

Proof of Work: Define criteria upfront, artifacts are the proof, document in `docs/work/` if no project conventions.

Task Tracking: Always use file-based tracking in `docs/work/`, session-based tools are ephemeral.
